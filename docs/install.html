How to install the app

A short, simple guide — from download to the first screen. No technical knowledge needed.

What you need: a Windows 10 or 11 computer (64-bit). That's it. Nothing to install, no account, and nothing is sent to the internet. The whole thing takes a few minutes — mostly the download.
1

Download the app

Click the button. A single file called TripVideo.zip will download (about 195 MB — depending on your connection this can take a minute or two).

Download Memowheel Pick TripVideo.zip from the list of files

The file usually lands in your Downloads folder.

2

Unzip the folder

The ZIP file is like a closed suitcase — you open it once:

  • Right-click the TripVideo.zip file.
  • Choose "Extract All…", then "Extract".

A folder called TripVideo appears, with all the app's files inside it.

Move the folder somewhere handy and permanent — your Desktop or Documents, for example. Don't put it inside Program Files: the app saves all your work there and needs a place it's allowed to write to.

3

Open it with a double-click

Go into the TripVideo folder and find TripVideo.exe (it may just show as TripVideo with a colorful icon). Double-click it.

The first launch can take a few seconds — that's normal.

4

If Windows shows a blue warning

The first time, you might see a blue box saying "Windows protected your PC". This happens for any new app that didn't come from a store — it is not an error and there's nothing wrong with the file.

  • Click the small "More info" link.
  • A "Run anyway" button appears — click it.

That's it — this only happens the first time.

5

The app opens

No ordinary window opens. Instead:

  • A small icon appears next to the clock in the corner of your screen (the system tray). Clicking it gives you: Open / View log / Quit.
  • Your browser opens automatically on the app's setup screen. This is where you start building your trip video.

Everything runs on your computer only — it just looks like a website, but no one on the internet can reach it.

From here, follow the User Guide (the "User Guide - English" file in the same folder).

Common questions

My antivirus blocks it or complains — what do I do?

Some security tools are cautious about brand-new apps. You can choose "Allow" or "Trust". Want to be sure the file wasn't changed? See "How do I check the download is genuine?" below.

Where do all my photos and the video get saved?

Everything is saved inside the TripVideo folder, next to the file you clicked. That's why it's best to keep the folder whole and in a permanent place, and not delete it.

How do I update to a new version?

Download again from the same link, unzip, and run the new version. Don't delete the old folder until you've copied out any work you want to keep.

How do I uninstall the app?

Just delete the TripVideo folder. There's no "uninstall" — the app installs nothing into your system.

How do I check the download is genuine? (optional)

Next to the download there's a small file called TripVideo.zip.sha256. For advanced users, it lets you confirm the file you downloaded is exactly the original. Most people can simply ignore it.
